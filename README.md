
# 🎓 KFUEIT CSS Club Website

A modern and responsive website developed for the **KFUEIT CSS Club** to provide students with information, resources, events, and membership opportunities. The platform is designed to create a digital presence for the club and make important CSS-related resources easily accessible.

## 🚀 Live Demo

🌐 Website: https://kfueit-css-club-website.netlify.app/

---

## 📌 Project Overview

The **KFUEIT CSS Club Website** is a frontend-based web application built to represent the CSS Club of **Khwaja Fareed University of Engineering & Information Technology (KFUEIT)**.

The website provides:
- Club introduction and information
- CSS exam preparation resources
- Membership application system
- Contact and communication features
- Dynamic form handling with Supabase integration

The goal of this project is to build an engaging, user-friendly, and informative platform for CSS aspirants and club members.

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

### 1. Clone Repository

```bash
git clone https://github.com/Muhammad-Bilal-Qadir/kfueit-css-club-website.git
````

### 2. Navigate to Project Folder

```bash
cd kfueit-css-club
```

### 3. Configure Supabase

Update `supabase-config.js` with your Supabase project credentials:

```javascript
const supabaseUrl = "YOUR_SUPABASE_URL";
const supabaseKey = "YOUR_SUPABASE_ANON_KEY";
```

### 4. Run Project

Open:

```
index.html
```

in your browser.
